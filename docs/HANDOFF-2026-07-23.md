O conteúdo novo está no `ContentData` (versionado), **não no Supabase**. Como o
**Supabase sobrescreve o ContentData**, enquanto o seed não rodar:
- a frase nova do **Público não aparece** (banco tem a antiga);

  banco), embora a LP renderize os 16 logos.

```bash

node apps/platform/scripts/seed-landing-revisao-2607.mjs         # aplica
```

no publicado é apagado no primeiro Publicar do cliente. Já aconteceu uma vez.
